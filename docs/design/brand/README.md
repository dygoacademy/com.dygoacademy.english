# Dygo brand: The Sprout

Two leaves on one stem: the word you planted, and the word that grew from it.
Design source: Dygo Word Garden canvas → **Brand** page (L1–L4).

## Colours
| Name | Hex | Use |
|---|---|---|
| Forest | `#24463A` | Mark circle, app icon background, theme colour |
| Leaf | `#9CC39A` | Stem, left leaf |
| Sprout | `#B7D6AE` | Right leaf |
| Cream | `#F4F1EA` | Page background, reversed wordmark |
| Ink | `#1C2B24` | Wordmark on light |
| Bee gold | `#F5C443` | Accent only (Dygo the bee) |

Wordmark: Fraunces SemiBold, tracking −2% (outlined in the SVGs, so no font needed).
Clear space: half the mark's width on every side. Smallest mark: 24 px on screen, 8 mm in print.

## Folders
- `logo/svg`, `logo/png`: mark and lockups (horizontal, stacked) in primary, reversed and one-colour versions.
- `favicon/`: copy these to the website's public root and paste `head-snippet.html` into `<head>`.
- `app-icon/ios`: `AppIcon-1024.png` (no alpha), `-dark`, `-tinted` for Xcode's single-size app icon.
- `app-icon/android`: adaptive icon layers (foreground SVG/PNG, monochrome, background colour `#24463A`).
- `app-icon/store`: Play Store 512 and App Store 1024.
